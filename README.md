# bayesian-multilevel-modeling
A Bayesian statistics term project exploring hierarchical models, partial pooling, shrinkage estimation, and Bayesian multilevel regression.

## Interactive presentation

The marimo notebook `notebooks/presentation.py` follows the sections of `report/main.tex` with interactive examples.

```bash
pixi run present   # app view (presentation)
pixi run edit      # edit mode
```

In section 6.4, press **Fit hierarchical model with PyMC** to run the sampler ("Report" mode reproduces Table 2 of the report).
